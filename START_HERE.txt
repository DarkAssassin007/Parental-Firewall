═══════════════════════════════════════════════════════════════════════
  🔍 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════

PROBLEM: "Permission Denied"
SOLUTION: Run as Administrator

PROBLEM: "No interfaces found"
SOLUTION: Install Npcap, enable network adapter

PROBLEM: Dashboard won't start
SOLUTION: Install dependencies (pip install -r requirements.txt)

PROBLEM: Firewall won't start
SOLUTION: Check Administrator rights, check Npcap

PROBLEM: No packets being blocked
SOLUTION: Verify filter is enabled, check interface selection

For more help: See setup_guide.txt

WHAT YOU'LL SEE IN LOGS:

🔴 Red (WARNING) - Blocked packets
   Example: "BLOCKED: 192.168.1.50 → 93.184.216.34"
   Reason: Blocked domain, Sensitive content, etc.

🟢 Green (INFO) - System messages
   Example: "Firewall started successfully"

💥 Red Bold (ERROR) - System errors
   Example: "Failed to capture packet"

STATISTICS TAB SHOWS:
   • Total packets blocked
   • Blocks by category
   • Firewall uptime
   • Configuration summary
