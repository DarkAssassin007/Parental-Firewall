📋 PREREQUISITES
================

1. Python 3.7 or higher installed
   Check: python --version

2. Administrator/Root privileges
   Windows: Run Command Prompt as Administrator
   Linux: Use sudo

3. Npcap installed (Windows only)
   Download: https://npcap.com/
   ⚠️ Install with "WinPcap API-compatible Mode" enabled


🔧 INSTALLATION STEPS
=====================

Step 1: Install Dependencies
-----------------------------
Open terminal/command prompt as Administrator and run:

    pip install -r requirements.txt

This will install:
- scapy (packet capture and analysis)
- colorama (colored terminal output)


Step 2: Verify Installation
---------------------------
Run this command to list network interfaces:

    python wifi_firewall.py --list-interfaces

You should see a list of network interfaces like:
  - Wi-Fi
  - Ethernet
  - Local Area Connection


Step 3: Configure Firewall Rules
---------------------------------
Option A: Use GUI Dashboard (Recommended)

    python firewall_dashboard.py

Then configure:
- Blocked domains (e.g., malicious-site.com)
- Blocked IP addresses
- Blocked keywords
- Click "Save All Settings"

Option B: Edit Configuration File Manually

Edit firewall_config.json with your preferred rules


Step 4: Start the Firewall
---------------------------
Run the firewall (replace "Wi-Fi" with your interface name):

    python wifi_firewall.py -i "Wi-Fi"

Or let it auto-detect:

    python wifi_firewall.py

⚙️ CONFIGURATION OPTIONS
=========================

Main Configuration File: firewall_config.json

Key Settings:
-------------

1. filter_enabled (true/false)
   - Enable or disable all filtering

2. sensitive_patterns (regex array)
   - Patterns to detect sensitive data
   - Default: credit cards, SSNs, passwords, API keys

3. blocked_domains (string array)
   - Domains to block
   - Example: ["malicious-site.com", "spam-domain.org"]

4. blocked_ips (string array)
   - IP addresses to block
   - Example: ["192.168.1.100", "10.0.0.50"]

5. blocked_keywords (string array)
   - Keywords that trigger blocking
   - Example: ["malware", "exploit", "hack"]

6. allowed_ips (string array)
   - IPs that bypass all filters
   - Example: ["127.0.0.1", "192.168.1.1"]


🛡️ SECURITY BEST PRACTICES
===========================

1. Always run with administrator privileges
2. Test configuration on non-critical networks first
3. Monitor logs regularly for false positives
4. Keep sensitive patterns up to date
5. Use whitelist (allowed_ips) for trusted devices
6. Regularly update blocked domains and IPs
7. Review firewall logs weekly


🔍 TROUBLESHOOTING
==================

Problem: "Permission Denied" or "Access Denied"
Solution: Run as Administrator (Windows) or with sudo (Linux)

Problem: "No network interfaces found"
Solution: 
- Install Npcap (Windows)
- Run with administrator privileges
- Check if network adapter is enabled

Problem: Firewall not blocking anything
Solution:
- Verify filter_enabled is true in config
- Check if interface is correct
- Ensure traffic is passing through the interface
- Test with known blocked domain

Problem: Too many false positives
Solution:
- Refine sensitive_patterns regex
- Use more specific keywords
- Add legitimate sites to allowed_ips

Problem: High CPU usage
Solution:
- Reduce number of sensitive patterns
- Use more specific blocking rules
- Monitor specific IP ranges only

🎯 TESTING YOUR FIREWALL
=========================

Test 1: Block a test domain
----------------------------
1. Add "example.com" to blocked_domains in config
2. Start firewall
3. Try to visit http://example.com
4. Check logs for blocking entry

Test 2: Detect sensitive pattern
---------------------------------
1. Ensure credit card pattern is in sensitive_patterns
2. Start firewall
3. Try to send a test credit card number (test only!)
4. Check logs for detection

Test 3: Block an IP
-------------------
1. Add an IP to blocked_ips
2. Start firewall
3. Try to connect to that IP
4. Verify blocking in logs


⚠️ IMPORTANT NOTES
==================

1. HTTPS/TLS Traffic:
   - Cannot inspect encrypted traffic without SSL interception
   - Most modern websites use HTTPS

2. Performance:
   - May slow down on high-traffic networks
   - Use specific filters to reduce load

3. Legal Compliance:
   - Only monitor networks you own or have authorization to monitor
   - Comply with local laws and regulations

4. False Positives:
   - Regex patterns may match legitimate content
   - Review and adjust patterns as needed

5. Backup:
   - Keep backup of firewall_config.json
   - Save logs before clearing them
